Ray's panels

The notes' look and spring, for anything that opens from a button. One panel at a time; it grows from its button and reshapes when its content changes. Click the sliders, the camera or download buttons, or use the bar above.

Behaviour

  • Grows from its button: 8 pt from the button's side and 97 % scale, anchored at the button, on the sidebar's spring (0.26 s, 0.86); fades in over 140 ms. Closes in 140 ms toward the button.
  • Content changes (the "…" page, a permission row appearing, a download finishing) reshape the panel on the same spring while the old content fades out and the new fades in. Back returns the same way.
  • One panel per window: opening another closes the open one first. Its button stays highlighted while it's open.
  • Closes on a click outside, Escape, a tab switch, the window going to the background, or (per panel) a navigation to another site.
  • A panel that asks (camera, save password) never closes on an outside click; its buttons ignore clicks for 0.5 s; closing it is "no". It shows the full origin.
  • Glass or Solid with the notes (one setting: Settings › Appearance › Panels and notes). Reduce Motion: fades only.
  • Extension popups stay a child window (a page can't sit under Ray's own views) but take the same corners, shadow and motion.

Proposed Swift API

/// What a panel hangs from: a button (the panel grows out of it) on one of its sides.
struct PanelAnchor { var view: NSView; var edge: NSRectEdge = .minY; var align: Align = .trailing }   // .leading, .center, .trailing

/// Any feature's panel: its content view plus how it behaves. `controller.panels.open(…)`.
struct PanelSpec {
  var content: NSView                    // sizes itself (fittingSize); built from PanelKit pieces or anything
  var anchor: PanelAnchor
  var closesOn: Set<PanelClose> = [.outsideClick, .escape, .tabSwitch, .windowInactive]   // + .navigation(origin)
  var asks = false                       // never closes on an outside click; buttons wait 0.5 s; closing is "no"
  var onClose: (() -> Void)? = nil
}

@discardableResult func open(_ spec: PanelSpec) -> PanelHandle   // closes the open one first

// handle.contentChanged()  — re-measure after the content grew or shrank (a permission row appeared)
// handle.close()

/// The pieces the screenshot's panel is made of, so a new prompt is a few lines:
enum PanelKit {
  static func tiles(_ items: [(symbol: String, label: String, action: () -> Void)], columns: Int = 4) -> NSView
  static func header(_ title: String) -> NSView
  static func row(icon: String, title: String, value: String?, action: (() -> Void)?) -> NSView
  static func separator() -> NSView
  static func buttons(_ actions: [PanelButton]) -> NSView           // last one primary (profile colour) when asking
  static func field(_ label: String, text: String) -> NSView
  static func stack(_ views: [NSView], spacing: CGFloat = 0) -> NSView
}

                      anchor: PanelAnchor(view: toolbar.sliders), closesOn: [.outsideClick, .escape, .tabSwitch, .navigation(origin)]))
