Settings: a calmer window

Each direction: the Appearance pane at full height (the real window is 600 pt tall and scrolls), light and dark, then Tabs and sidebar › New tabs, then About Ray. New in A, B and C: Check Now beside the version (General’s same button and call, only when there’s an updater; General keeps its own). Profile colour: the default lavender.

What's ugly today, beyond the picture rows:

  • Picture rows are 84 pt, nearly twice a plain row: the picture floats mid-row and the switch hangs off its right.
  • No grouping: rows float on the page and hairlines run edge to edge, so a group header reads like one more row (both 13 pt).
  • Header to first row is the same gap as group to group, so groups don't hold together.
  • "Theme", then "Theme colour", then the swatches: three stacked labels before anything to click; the light/dark pictures leave half the row empty.
  • Trailing controls change height row to row (switch 22, segmented 26, pop-up 24, button 28) and the segmented control's lavender pill shouts louder than the switches.
  • Sidebar: 34 pt rows and a heavy 30 pt search field feel large next to 13 pt text; "All Chrome Settings…" in the accent colour competes with the selected pane.

References: Dia (Cra measured it) and Ardia put rows in rounded cards: 43 pt rows, 10–14 pt insets, inset dividers, 13 pt semibold headers just above the card. Ardia shows pictures only as choices (Light / Dark / Automatic, app icon) above or inside a card, never next to a switch. Arc's own settings also use rounded boxes. Crest uses macOS's grouped form, also cards.
