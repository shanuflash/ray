What changes from today

  1. New Space (the footer's +, now a menu as Arc's: New Space, New Folder, New Tab) turns the sidebar into this form again (Arc's, replacing the 4B panel). Edit Space… uses the same form, titled Edit Space, with Done and Delete Space….
  2. The icon is Arc's picker: every Mac emoji with search (by name) and Arc's category tabs, or Icon for a symbol; the trash clears it. The same picker opens from a footer icon's menu (Change Icon…).
  3. Theme opens a panel beside the sidebar: light, auto or dark for the Space, the Window colour with a strength slider (Ray's light wash up to Arc's full colour), and the Accent. Arc's gradients and grain stay out.
  4. New Profile… is a card over the window, as Arc's; the new profile is picked when it's made.
  5. Create Space: the icon pops in the middle of the sidebar and goes, then the empty Space shows (with a "Drag to add favorites" hint when its profile has none).
