Folders in Pinned and Today

One idea, “Folder”, in both sections. Pinned folders are the ones Ray has now. Today folders are new: each is a Chrome tab group underneath, so Chrome's tab group API sees and drives them. An extension's group (Claude's) shows up as a Today folder.

Engine check (hidden test instance): an extension's group, rename, colour, collapse and ungroup all work today, with no engine rebuild. Only Ray's sidebar is missing.

The look

Same row in both sections: folder icon in the folder's colour (grey with none), name, chevron. Tabs step in 16 pt. A closed folder keeps the active tab in sight and shows how many tabs it holds.

Pin FolderIts tabs become pinned tabs in a pinned folder, and it stops being a Chrome group. Why: Chrome never lets a pinned tab sit in a group, and a pinned folder holds unloaded tabs that aren't Chrome tabs at all, so an extension would see a group whose tabs come and go. An extension that still wants its tabs grouped makes a new group, which shows up as a new Today folder
