Three parts to pick: the picker, the bar while sharing, and the marks on a shared tab. The first variant of each is my recommendation.

Why sharing Ray's own window failed

Ray's window is a Chrome window under the hood (a views widget, so the engine can host the page). Chrome's picker sees that and, as it does for its own windows, records it as “capture this widget through Chrome's compositor” instead of asking macOS for its pixels. Chrome's compositor never draws Ray's sidebar or the page's own layers, so the capture fails. Ray's picker asks for every window, Ray's included, by its macOS window number only, so macOS captures what's on screen like any other app's window. Ray's own windows stay in the list (Chrome lists its own too); the picker itself is inside the window and closes before sharing starts.
