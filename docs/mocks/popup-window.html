Pop-up window

A page's sized pop-up (window.open with a width and height: Google, Apple and Microsoft sign-ins, payment checks, "Connect to Slack") opens in its own small window at the size the page asked, over Ray's window, as Arc, Chrome and Ardia do. Today Ray makes it a Today tab. Every option shows the pop-up's full origin (a pop-up can be any site), never page text where the address goes, and closes when the page closes itself after the sign-in. ⌘W closes it; it has no sidebar, tabs or command bar. Links it opens in a new tab go to Ray's window.

A · Title bar and an address strip Chrome / Ardia

macOS's title bar with the page's title, then a read-only 28 pt strip: lock, host, path in grey. The most familiar; two rows of chrome.

Sign in – Google Accounts

B · One row in Ray's colour, page as a card Ray's look

Ray's sidebar colour framing the page card, as Ray's own window does: the traffic lights, the address centred, and an "Open as Tab" button (moves the page into a Today tab in Ray's window). One row of chrome; looks like part of Ray rather than a stray window.

C · The address in the title bar

macOS's title bar alone, its title replaced by the address (lock, host, path). The least chrome; no way to move it into a tab (drag-free).
