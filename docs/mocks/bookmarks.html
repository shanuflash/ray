Bookmarks in Ray

MISSING Chrome 1. Today ⌘D pins (Arc's), and imported bookmarks sit in Chrome's model under "Imported from <Browser>", reachable only at chrome://bookmarks. The engine already has what every option needs: ac_bookmarks_tree, ac_bookmarks_apply (add, move, rename, remove), ac_bookmarks_watch, and ac_favicons_get. No engine rebuild for any of them.

What the others do

ArcNo bookmarks. Import turns them into pinned folders; ⌘D pins. Command bar finds pinned tabs.
ChromeBookmarks menu (⌘D, ⇧⌘D all tabs, ⌥⌘B manager, then the bar's folders, Other Bookmarks), bookmarks bar, omnibox ranks bookmarks high.
ArdiaAll of Chrome's: menu bar Bookmarks menu built from the model, its own Bookmarks page, a bar (off by default), omnibox rows, "Add to Sidebar as Group" and "Restore Arc Folders as Groups".
CrestNone. ⌘D pins ("Crest keeps a page by pinning its tab").
CraNone. Import puts bookmarks into the sidebar as pinned folders (Other Bookmarks as its own 🔖 space).

In every option: the command bar finds bookmarks shared

A bookmark that matches shows as a page row with "Bookmark" on the right (where open tabs say "Switch to Tab"), ranked with the pages you go to; one you've never visited still shows. An open tab on the same address wins and the bookmark row steps aside. Enter opens it in a new Today tab.

A. Bookmarks menu in the menu bar recommended

Chrome's and Ardia's menu, built from the model each time it opens: favicons, folders as submenus, "Open All" and "Add to Pinned" at the end of each folder. ⌘D stays Pin Tab (Arc's); "Bookmark This Tab…" has no key until you give it one in Settings › Shortcuts. "Show All Bookmarks" opens chrome://bookmarks, which already works for renaming, sorting and deleting.

B. Bookmarks panel from the sidebar

A bookmark button in the sidebar footer (next to Downloads; ⌥⌘B) opens an in-window panel over the sidebar, like the downloads list: a search field and the tree as sidebar-like rows, folders opening in place. Right-click: Open in New Tab, Copy Link, Rename…, Delete; a folder adds Open All and Add to Pinned. Rows drag into the sidebar to pin. Plus the menu bar's Bookmarks menu from A.

C. Arc's way: bookmarks become pinned

No bookmarks UI. After an import that brought bookmarks (and once for an "Imported from …" folder already there) a question asks to move them into Pinned as a folder, tabs asleep until opened. The command bar still finds whatever stays in Chrome's model, and "Show All Bookmarks" in the command bar opens chrome://bookmarks.
