Behaviour (same for every option)

  • Hint shows when what you typed starts a site search's name or keyword: “y” → YouTube, “wiki” → Wikipedia. Several match: the one you use most, then list order.
  • Built-in site searches: Arc's list (YouTube, Wikipedia, GitHub, Google Maps / Drive / Docs / Calendar, Amazon, Reddit, X, Spotify, Figma, LinkedIn, Pinterest, Stack Overflow…), plus your own and the engines.
  • Colour: a built-in table for those (as Arc's), your own site searches take their icon's main colour, else the profile colour. Text on it is white or black, whichever reads.
  • Return searches the site; Delete with nothing typed leaves the scope (as today).
